# Скриншоты приложения

Добавьте 2–4 изображения ключевых экранов готового приложения и вставьте их относительными ссылками в основной README.

Покажите основные функции своей темы: список данных, форму операции, отчёт или другой значимый экран. Используйте понятные имена файлов и короткие подписи. Скриншоты должны соответствовать текущей версии приложения и не содержать паролей или токенов.
