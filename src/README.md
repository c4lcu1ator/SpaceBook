# Исходный код приложения

Создайте в этой папке решение и проект C# с интерфейсом WPF. Windows Forms допускается по согласованию с преподавателем.

1. Выберите поддерживаемую версию .NET, совместимую с учебными компьютерами.
2. Используйте осмысленные имена решения, проекта и пространств имён.
3. Подключите `Microsoft.Data.SqlClient` и реализуйте доступ к SQL Server через ADO.NET.
4. Разделите интерфейс, предметную логику и доступ к данным по классам/компонентам. Структуру папок определите самостоятельно; MVVM и DI не обязательны.
5. Укажите в основном README путь к решению/проекту, версии зависимостей и порядок запуска.

В репозиторий должны попасть исходники, ресурсы и файлы решения/проекта. Каталоги `.vs/`, `bin/`, `obj/` и локальные настройки с секретами исключаются через `.gitignore`.

Не размещайте SQL непосредственно в обработчиках кнопок. Пользовательские значения передавайте параметрами. Для связанных изменений используйте транзакцию с фиксацией при успехе и откатом при ошибке.

После создания приложения этот файл можно заменить кратким описанием фактической структуры исходного кода.
