## 8. Технические требования

- C#, WPF (Windows Forms — по согласованию), Microsoft SQL Server.
- Доступ к данным через ADO.NET и `Microsoft.Data.SqlClient`.
- Пользовательские значения передаются через SQL-параметры.
- Предметная логика и доступ к данным отделены от интерфейса; SQL не размещается непосредственно в обработчиках кнопок.
- Соединения и другие ресурсы корректно освобождаются.
- При ошибке приложение показывает понятное сообщение без паролей и секретов.
- Проект разворачивается на другом учебном компьютере по README и SQL-скриптам.
